Privacy

Last updated 15 October 2026

This website sets no cookies, runs no analytics and has no forms. The app reads files on your own machine and sends nothing anywhere. That is the whole policy; the rest is detail.

The website

agentisland.in is one static page served by Cloudflare. It collects nothing from you directly: there is no form, no sign-in, no tracking script, and nothing is written to your browser's storage.

What others see when you visit

Two parties receive technical information as an unavoidable part of serving the page:

  • Cloudflare hosts the site and processes standard server logs, including your IP address, for security and delivery. See Cloudflare's privacy policy.
  • Google Fonts serves the two typefaces this page uses, so your browser requests them from fonts.gstatic.com and Google receives your IP address. See Google's privacy policy.

Neither is used by us to build any profile of you, and we do not receive any of it in a form that identifies you.

The app

Agent Island is a macOS app that runs entirely on your computer. It reads the session files your coding agents already write to your own disk, in order to show them in the notch.

  • Nothing is uploaded. The app has no server and makes no network request to us. Your prompts, code, session titles and spend never leave your machine.
  • No account. There is nothing to sign in to.
  • Diagnostics stay local. Exporting diagnostics writes a folder to your Desktop and reveals it in Finder so you can read it before deciding whether to share it. It is never sent anywhere automatically.
  • Update checks. If automatic updates are enabled, the app asks a release feed whether a newer version exists. That request carries only what any HTTP request carries. It can be switched off in Settings.

Your rights

Because we hold no personal data about you, there is nothing for us to export, correct or delete. Requests about the server logs or font requests described above should go to Cloudflare or Google, who act as the controllers of that data.

Changes

If this ever stops being true, for example if analytics are added, this page will be updated before that change ships, and the date at the top will change with it.
